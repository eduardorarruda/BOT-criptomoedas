# Marca ZenTrade

**Símbolo: Ensō.** O círculo do zen, desenhado com compasso, aberto num único ponto; na abertura, um candle. O círculo é a calma, o candle é a decisão: o robô passa a maior parte do tempo esperando e age só quando há motivo.

| Arquivo             | Uso                                             |
| ------------------- | ----------------------------------------------- |
| `simbolo.svg`       | fundo escuro (anel papel de arroz, candle jade) |
| `simbolo-claro.svg` | fundo claro (anel tinta, candle jade profundo)  |

**Cores:** tinta `#070C0A` · superfície `#0D1512` · jade `#3DDC8E` · jade profundo `#0E6B47` · papel de arroz `#E6EEE8` · coral `#FF6F61` (perda) · âmbar `#E9B44C` (atenção).

**Tipografia:** Instrument Serif itálica para “Zen” e títulos; Geist para interface e texto; Geist Mono para todo número.

**Não fazer:** moedas, Bitcoin, setas, escudo, neon, 3D ou brilho no símbolo. O verde é chapado.
